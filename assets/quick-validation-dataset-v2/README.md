# Quick validation dataset v2

This archive contains a small synthetic six-view dataset for the public AMD
Nerfstudio / Nerfacto installer validation path.

## Purpose

- installation validation;
- real P0 runtime / provenance preflight;
- real P1 short Nerfacto mechanics validation.

## Non-claims

This dataset is **not** intended to prove:

- reconstruction quality on real-world scenes;
- geometric accuracy;
- photorealism;
- generalization performance.

## Contents

- 6 PNG images (`000.png` to `005.png`)
- `transforms.json`
- `DATASET_PROVENANCE.json`
- `SHA256SUMS.txt`
