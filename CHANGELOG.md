# Changelog

## v1.4.3 - Existing-environment advisory package policy

- keep the Fresh-ENV wheelhouse and installed-runtime package exclusions strict;
- treat `yourdfpy`, `pyliblzfse`, and multiple installed OpenCV distributions as recorded advisories for an explicitly selected existing environment;
- retain fail-closed Viewer construction, exact runtime identities, immutable `pip freeze`, and real P0+P1 as the reuse qualification gates;
- add self-test and unit regression coverage proving advisory package observations do not block an otherwise qualified shared environment.

## v1.4.2 - Explicit environment routing and apply validation fix

- make the adaptive shell wrapper use the exact `set -euo pipefail` form required by the existing public-tree audit;
- retain visible wrapper errors through the existing `ERR` trap and interactive pause.

- require the user-selected environment explicitly instead of searching or silently using system Python;
- route apply syntax checks, self-tests, unit tests and public-tree audit through `ENV_ROOT/bin/python`;
- keep interactive failures visible while preserving non-zero fail-closed status;
- remove generated bytecode before tree audit and restore a payload-consistent repository hash manifest;
- add the missing adaptive Python shebang and exact-environment contract tests.

## v1.4.0 - Adaptive environment installer

- add an adaptive venv/Conda/system-Python detector and non-mutating reuse path;
- add safe isolated fallback and repair semantics through the existing Fresh-ENV installer;
- make `pip check` advisory for shared-environment reuse while retaining P0+P1 as the scoped gate;
- add plan, quick, verify, no-test, full-test, cleanup and provenance modes;
- pin `viser==1.0.0` as the required math-only `viser.transforms` dependency while Viewer construction remains fail-closed;
- add adaptive installer self-tests, contract tests and documentation.
